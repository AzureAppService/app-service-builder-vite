How to change your public greeting

In your Builder App, set the build-time variable VITE_SAMPLE_GREETING to your own public text, then save and deploy a new version. Vite embeds it in the static files; a runtime-only change will not update this page. Never put a secret in a VITE_* variable.

For a local build, set it before running npm run build. Without a value, this page uses Hello from Vite.
